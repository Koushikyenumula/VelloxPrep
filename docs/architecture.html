System Overview

High-level understanding of the VelloxPrep ecosystem.

VelloxPrep is an application that acts like a robot recruiter. You (the user) talk to the website through your browser. The website sends your requests to our backend server. Our server stores your info safely, and talks to Google's Gemini AI to grade your answers.
VelloxPrep utilizes a decoupled client-server architecture. The Client is a static Vanilla JS frontend. The Backend is a monolithic Spring Boot API (Java 21) handling RESTful communications. Data persistence is managed via Hibernate JPA into a serverless Neon PostgreSQL database. Logic is heavily delegated to the Google Gemini 1.5 Flash LLM.

Request Lifecycle

What happens when a user clicks "Start Interview"?

1
Frontend Button Click
Website catches the click and prepares the user's resume data.
File: interview.js
Action: fetch('/api/interview/start', { headers: {'Authorization': 'Bearer ' + token} })
2
Spring Boot Authentication Filter
Backend checks the user's VIP pass (token) to ensure they are allowed in.
Class: JwtAuthenticationFilter.java
Action: Intercepts request, validates JWT signature, sets SecurityContext.
3
Controller & Service Logic
The backend creates a new empty interview session in the database.
Class: InterviewController.java -> InterviewSessionServiceImpl.java
Action: sessionRepo.save(newSession)
4
Gemini AI Prompt Injection
Backend talks to Google AI asking it to generate 5 tech questions for the user.
Class: GeminiServiceImpl.java
Network: Sync HTTP POST to generativelanguage.googleapis.com
